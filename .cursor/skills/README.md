# Design skills used for the Rooks window

These were added so the native window could be redesigned against written craft rules, not a generic template.

- `emil-design-eng/` — Emil Kowalski, MIT. Polish, hierarchy, and not animating things people use all day.
- `impeccable/` — Paul Bakaus, Apache-2.0. Anti-generic product UI: one point of view, no card walls, verify by looking.
- `taste-skill/` — Leonxlnx, MIT. Plain words, one system, equal edges, and a real look at the screen instead of assuming the page is fine.

The window itself is iced, so it is checked with screenshots of the running app, not a browser page.
