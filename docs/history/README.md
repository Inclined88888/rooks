# History

Dated audits, gate reports and evidence from earlier branches, kept as a record. They describe the repository as it
was when each was written; they are not current guides. For how Rooks is built today, read
[architecture.md](../architecture.md).

| File | What it was |
| --- | --- |
| [AUDIT.md](AUDIT.md) | A security audit of an earlier branch |
| [PHASE0-GATE.md](PHASE0-GATE.md) | The Phase 0 acceptance gate |
| [ROOKS-FINISH-REPORT.md](ROOKS-FINISH-REPORT.md) | The finish report for the first Rooks terminal work |
| [evidence/](evidence/) | Inventories and UI evidence (screens, accessibility trees) behind those reports |
| [night/](night/) | Progress notes from an overnight run |
| [scripts/audit/](scripts/audit/) | The scripts that regenerated the evidence pages |

Paths inside these files are the ones they had when written: `docs/evidence/` is now `docs/history/evidence/`,
`scripts/audit/` is now `docs/history/scripts/audit/`, and `docs/AUDIT.md`, `docs/PHASE0-GATE.md` and
`docs/ROOKS-FINISH-REPORT.md` are now in this folder. The two scripts were updated to the new paths.
